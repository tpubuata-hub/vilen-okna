# Вилен Окна

Одностраничный сайт для компании «Вилен Окна»: пластиковые окна и остекление балконов в Новосибирске.

**Сайт:** https://tpubuata-hub.github.io/vilen-okna/

## Что внутри

- Первый экран: заголовок, подзаголовок и две кнопки слева, фото светлой квартиры справа, полоса из четырёх преимуществ снизу. На 1920×1080 занимает ровно один экран.
- Услуги заказчика: окна под ключ, ремонт окон, продажа и доставка. Заказчик дилер профилей REHAU, SCHMITZ и EXPROF.
- Конструктор запроса на расчёт окна и балкона со схемой в стиле эскиза замерщика. Цен на сайте нет (заказчик называет их по запросу): параметры уходят в WhatsApp или на почту.
- Наши работы: 9 настоящих фото с объектов компании (8 объектов) и просмотр на весь экран со стрелками, свайпом и клавиатурой.
- Отзывы из 2ГИС, контакты с почтой, карта.
- Адаптив под телефоны, режим «уменьшить движение», доступность с клавиатуры.

Стек: HTML, CSS, JavaScript без сборки. Анимация: GSAP + ScrollTrigger, плавная прокрутка: Lenis (лежат в `assets/vendor`). Шрифт Inter.

## Как запустить локально

```bash
python -m http.server 8000
```

и открыть http://localhost:8000

## Настройки

Все настройки в `assets/js/config.js`: телефоны, WhatsApp, почта и `formEndpoint`.

- Пока `formEndpoint` пустой, кнопки заявок открывают готовое сообщение в WhatsApp (+7 952 901-20-57) или письмо на okna54.vit@mail.ru.
- Если указать URL (веб-приложение Google Apps Script или вебхук Telegram-бота), заявки будут уходить POST-запросом с JSON `{ source, name, phone, topic, comment, calc, text, page, date }`, а кнопка «на почту» спрячется.

## Логотип

Файла логотипа в проекте не было, поэтому знак нарисован в SVG прямо в разметке по референсу (синяя рама окна с импостом и ручкой). Если у клиента есть оригинальный файл, замените оба блока `brand__mark` в `index.html`.

## Фото

- `assets/img/works/`: настоящие фото объектов от заказчика. Подпись камеры «Galaxy S23 FE» обрезана. Для каждого фото две версии: `name-sm.webp` (800 px, для сетки) и `name.webp` (1280 px, для просмотра).
- Блок «Балконы» и балконы в «Наших работах»: тоже фото заказчика.
- Первый экран и плитка «Квартира»: фото с Unsplash (бесплатная лицензия), настоящих фото интерьеров пока нет.

Отзывы в блоке «Отзывы» взяты из открытой карточки компании в 2ГИС (рейтинг 4,8, 40 отзывов).
