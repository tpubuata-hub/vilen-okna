# Вилен Окна

Одностраничный сайт для компании «Вилен Окна»: пластиковые окна и остекление балконов в Новосибирске.

**Сайт:** https://tpubuata-hub.github.io/vilen-okna/

## Что внутри

- Первый экран: заголовок, подзаголовок и две кнопки слева, фото светлой квартиры с панорамными окнами справа, полоса из четырёх преимуществ снизу. На 1920×1080 занимает ровно один экран.
- Калькулятор окна и балкона со схемой в стиле эскиза замерщика. Створки переключаются кликом, цена пересчитывается сразу.
- Варианты остекления балконов, этапы работы, слайдер «до и после», галерея, отзывы из 2ГИС, контакты и карта.
- Адаптив под телефоны, режим «уменьшить движение», доступность с клавиатуры.

Стек: HTML, CSS, JavaScript без сборки. Анимация: GSAP + ScrollTrigger, плавная прокрутка: Lenis (лежат в `assets/vendor`). Шрифт Inter.

## Как запустить локально

```bash
python -m http.server 8000
```

и открыть http://localhost:8000

## Что настроить перед запуском для клиента

Все настройки в `assets/js/config.js`:

- `prices`: цены калькулятора. Сейчас там ориентировочные значения, их нужно согласовать с заказчиком.
- `formEndpoint`: куда отправлять заявки. Пока пусто, и заявка открывается готовым сообщением в WhatsApp на +7-952-901-20-57. Если указать URL (веб-приложение Google Apps Script или вебхук Telegram-бота), заявки будут уходить POST-запросом с JSON:
  `{ source, name, phone, topic, comment, calc, text, page, date }`.

## Логотип

Файла логотипа в проекте не было, поэтому знак нарисован в SVG прямо в разметке по референсу (синяя рама окна с импостом и ручкой). Если у клиента есть оригинальный файл, замените оба блока `brand__mark` в `index.html`.

## Фото

Фото в `assets/img` взяты с Unsplash (бесплатная лицензия) и стоят как временные. Фото первого экрана: `hero-interior-1280.webp` и `hero-interior-2400.webp` (для ретины). Блок «Наши работы» и слайдер «до и после» нужно заменить на реальные фото объектов компании с теми же именами файлов.

Отзывы в блоке «Отзывы» взяты из открытой карточки компании в 2ГИС (рейтинг 4,8, 40 отзывов).
